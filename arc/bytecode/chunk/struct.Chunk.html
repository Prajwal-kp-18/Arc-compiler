pub fn add_constant(&mut self, value: Value) -> u16

Adds a value to the constant pool and returns its index.

Panics if the pool exceeds u16::MAX entries — no program anywhere near that size exists today; this is a hard limit inherent to the u16 operand width, not a recoverable error.

Source

pub fn emit_jump(&mut self, op: OpCode, source_offset: u32) -> usize

Emits op with a placeholder u16 operand and returns the offset of that operand, to be patched later via Chunk::patch_jump once the jump target is known.

Source

pub fn patch_jump(&mut self, operand_at: usize)

Patches a jump emitted at operand_at (as returned by Chunk::emit_jump) to land at the current end of the chunk.

Source

pub fn patch_jump_to(&mut self, operand_at: usize, target: usize)

Patches a jump emitted at operand_at to land at target (a code offset at or after the operand — jumps are forward-only).

Source

pub fn emit_loop(&mut self, loop_start: usize, source_offset: u32)

Emits an OP_LOOP (backward jump) landing at loop_start, a code offset already behind the current end of the chunk — the loop header’s start is always known by the time the back-edge is emitted, so unlike forward jumps this needs no later patching.
