Struct CompiledProgram 

Source 
pub struct CompiledProgram {
    pub script: Chunk,
    pub functions: Vec<CompiledFunction>,
    pub script_frame_size: u32,
}
Expand description

The output of a compile pass: the top-level “script” chunk, plus one compiled function per FunctionId, indexed by FunctionId.0.

Fields§

§script: Chunk§functions: Vec<CompiledFunction>§script_frame_size: u32

Local slots the script frame needs. Zero for directly-compiled programs (script variables are globals); non-zero when the IR pipeline spills the script’s virtual registers to frame slots.
