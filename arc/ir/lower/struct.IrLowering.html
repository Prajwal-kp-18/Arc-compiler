fn lower_while(&mut self, while_stmt: &ASTWhileStatement)

Lowers while <cond> { body } into a header/body/exit triple: the header re-evaluates the condition and branches into the body or out to the exit block; the body’s fall-through end jumps back to the header — the CFG’s one back-edge (header’s block id is always lower than body’s, since header is created first).
