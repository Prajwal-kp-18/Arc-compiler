Binary

A non-logical binary operation (&&/|| never reach the IR — they lower to control flow). can_error is the shared purity fact every pass keys off: true if this op could raise a runtime error (division/modulo by zero, ** overflow, or any operand typed Any), in which case folding skips error results and DCE/CSE leave it alone.

Negate

Arithmetic negation. Errors at runtime on non-numeric values, so it carries its own can_error (true iff the operand’s static type is Any).

pub fn is_pure(&self) -> bool

Whether the instruction is removable when its result is unused: no side effects and provably unable to raise a runtime error. Deleting a potential runtime error is a behavior change, so Binary/Negate consult the can_error fact computed at lowering.
