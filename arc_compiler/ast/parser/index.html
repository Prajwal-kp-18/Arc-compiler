§Parser

Converts a flat token stream from the Lexer into an Abstract Syntax Tree using recursive descent with operator-precedence climbing for binary expressions.

§Statement dispatch

Parser::parse_statement uses one token of lookahead to decide:

  • let / const → variable declaration
  • fn → function declaration
  • return → return statement
  • identifier = → assignment
  • anything else → expression statement
