§AST Module

Defines the Abstract Syntax Tree node types and the ASTVisitor trait used by the evaluator and printer.

§Structure

An Ast holds a list of ASTStatements. Each statement is either:

  • An expression (evaluated for its value)
  • A variable declaration (let / const)
  • An assignment (x = expr)

Expressions are represented as ASTExpression nodes, which may be literals, identifiers, binary/unary operations, parenthesized groups, or function calls.

§Visitor Pattern

Implement ASTVisitor to traverse the tree. The evaluator and ASTPrintor both use this pattern.
